# Synthetic Fixture

The synthetic scenario is generated by the SQL files in [`../sql/01-data/`](../sql/01-data/).
There is intentionally no production extract, customer record, or external data download in this directory.

The seed creates one delayed-arrival scenario with:

- one inbound vessel, voyage, and port call;
- a revisioned ETA event history;
- 36 container connections across 18 synthetic bookings; and
- expected `MISS` / `TIGHT` / `KEEP` cohorts used by the validation scripts.

The expected counts and scenario contract are stored in [`../tests/expected/`](../tests/expected/). They are test assertions for a synthetic fixture, not an operational recommendation.
