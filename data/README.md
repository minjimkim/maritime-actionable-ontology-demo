# 합성 시나리오 데이터

합성 시나리오는 [`../sql/01-data/`](../sql/01-data/)의 SQL 파일로 생성합니다. 이 디렉터리에는 운영 데이터 추출본, 고객 레코드, 외부 다운로드 데이터가 포함되지 않습니다.

Seed 스크립트는 다음 내용을 가진 하나의 입항 지연 시나리오를 생성합니다.

- 입항 선박, 항차, 기항 각 1건
- revision 이력이 있는 ETA 이벤트
- 합성 예약 18건에 연결된 컨테이너 환적 연결 36건
- 검증 스크립트에서 사용하는 `MISS`, `TIGHT`, `KEEP` 기대 집합

기대 건수와 시나리오 계약은 [`../tests/expected/`](../tests/expected/)에 저장되어 있습니다. 이는 합성 fixture를 검증하기 위한 기준이며 운영 권고가 아닙니다.
